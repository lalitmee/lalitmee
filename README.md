## Apps & tools

- **[Markdown Previewer](https://github.com/lalitmee/markdown-previewer)** — Read, search, and edit local Markdown files with live preview and Mermaid diagrams. [Try it](https://markdown-assistant.vercel.app/).
- **[JSON Assistant](https://github.com/lalitmee/json-assistant)** — Inspect and edit JSON in code, tree, or split views; format, search, and export without uploading documents. [Try it](https://json-assistant-one.vercel.app/).
- **[Jira Assistant](https://github.com/lalitmee/jira-assistant)** — Local-first Jira Cloud worklog auditor with month and week calendars for reviewing logged time. Set it up locally from the repo.
